# Gerador de QR Code Wi‑Fi

Projeto simples e funcional para gerar cartões de Wi‑Fi em PDF A4, prontos para impressão e recorte.

## O que ele faz
- Cria um QR Code com os dados da rede Wi‑Fi
- Suporta WPA/WEP e redes abertas
- Permite mostrar ou ocultar a senha no cartão
- Gera uma folha com 6 cartões por página
- Exibe uma pré-visualização antes da geração do PDF

## Tecnologias
- HTML
- CSS
- JavaScript
- QRCode Generator
- jsPDF

## Como usar
1. Abra o arquivo `index.html` no navegador
2. Preencha o nome da rede, criptografia e senha
3. Clique em `Gerar PDF`
4. Imprima e recorte os cartões

## Observação
O projeto foi organizado em arquivos separados para facilitar manutenção e evolução futura.

## Perfil do projeto
Aplicação front-end de uso prático, com foco em produtividade, usabilidade e geração de documentos diretamente no navegador.
